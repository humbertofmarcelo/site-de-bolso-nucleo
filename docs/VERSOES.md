### Entenda o que são:

As versões são apresentadas a partir das tags, então sempre use git tag para determinar uma nova versão

Modelo:

nome-v1.1.1
nome - dominio do cliente
- Primeiro dígito = Versão geral do site. Inclui mudanças estruturais muito grandes
- Segundo dígito = features, check das fases, commit mais comum
- Terceiro dígito = ajustes pequenos e correção de bugs. 

Ex:

psiamandabertotti-v2.39.2
- Este modelo está usando o template versão 2 do site, está na 39ª etapada funcional e recebeu 2 revisões de correção dentro desta etapa.
